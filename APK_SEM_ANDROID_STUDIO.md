# Gerar o APK sem Android Studio (pelo site do GitHub)

1. Crie conta grátis em github.com e clique em **New repository** (nome: nutridigest, pode ser Private). Crie.
2. Na página do repositório: **uploading an existing file**. Arraste TODOS os arquivos e pastas deste projeto
   (inclusive a pasta oculta `.github`) e clique **Commit changes**.
   Dica: se a pasta oculta não subir pelo arrastar, use o GitHub Desktop.
3. Abra a aba **Actions**. O "Gerar APK" roda sozinho (uns 5 min).
4. Quando ficar verde, clique nele e, em **Artifacts**, baixe **NutriDigest-APK**.
5. Descompacte, mande o `app-debug.apk` pro celular e instale.
